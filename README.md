## Add a new Agency to the List

- [Fork](https://guides.github.com/activities/forking) the repository
- Add your agency in alphabetical order using the format below
- Agency description should be short and should not end with a period
- Only agencies that offer digital marketing as a core service (social media, ads, SEO, content or branding) will be accepted

### Format

```
- [Agency Name](https://my.agency) | location, city | what does it do
``` 
### Duds

If you cannot provide a valid website for your agency, your PR will not be accepted.
